# F-Droid Repository

Custom F-Droid repository for HydraMeshnet apps.

## How to add this repo to F-Droid

1. Open F-Droid app
2. Go to Settings > Repositories
3. Add new repository with URL:

```
https://hydrameshnet.github.io/fdroid/repo
```
